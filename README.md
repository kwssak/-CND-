для начала что такое CDN
Простыми словами, CDN (Content Delivery Network) — это сеть серверов, разбросанных по всему миру, которые помогают сайтам и приложениям загружаться быстрее для пользователей из любой точки.

Представьте, что вы заказали книгу из книжного магазина, который находится в другом городе. Вместо того чтобы ждать доставку через всю страну, магазин заранее развозит копии популярных книг по маленьким складам в разных районах. Когда вы заказываете, вам привозят книгу с ближайшего склада.
CDN работает так же 
в чем заключается суть обхода? 
В условиях белых списков обычные VPN-протоколы перестают работать, потому что провайдер пропускает только трафик к заранее одобренным адресам (например, Яндекс, VK, Сбер). Обход через CDN и VLESS XHTTP строится на том, чтобы спрятать ваш трафик внутри разрешённого.

Вот сжатая суть.

Как это работает

Схема выглядит так:

Клиент → VLESS/XHTTP → TLS → CDN (белый) → Nginx (источник) → Xray → Интернет

Ключевой момент: CDN-провайдер должен иметь узлы в подсетях, которые входят в белый список. В России это, как правило, Yandex Cloud, VK Cloud, Beeline, Timeweb. Вы арендуете у них CDN или VPS, и трафик клиента идёт на этот «белый» IP.

Причём тут VLESS XHTTP

VLESS — это протокол, который идентифицирует пользователя и передаёт данные.
XHTTP — это транспорт поверх HTTP. Он превращает VPN-трафик в обычные HTTP-запросы (GET/POST) к вашему серверу.

Зачем это нужно:

1. Маскировка под обычный HTTPS. Для провайдера это выглядит как посещение сайта, который в белом списке, а не как VPN.
2. Обход проверки SNI. DPI (система фильтрации) сверяет домен в TLS-запросе с IP-адресом. XHTTP позволяет использовать домен, который соответствует «белому» IP, чтобы проверка прошла.
3. CDN как «прикрытие». CDN-провайдер терминирует TLS на своей стороне. Заблокировать его массово нельзя, потому что от него зависит работа разрешённых сайтов.

# требования 
· VPS в России (VK Cloud, Yandex Cloud, Timeweb) - это сервер, где будет стоять Xray и куда CDN будет передавать трафик, арендуется в панели провайдера
· Домен для origin-сервера - технический адрес, на который CDN будет проксировать запросы, покупается у любого регистратора или берется бесплатно
· CDN-ресурс у российского провайдера - сервис, который принимает трафик клиента и передает его на origin, настраивается в панели CDN (VK Cloud, Yandex Cloud, Timeweb и другие)
· SSL-сертификат для домена origin - нужен для шифрования между CDN и вашим сервером, бесплатно получается через Let's Encrypt (certbot)
· Nginx на VPS - обратный прокси, который принимает запросы от CDN и передает их в Xray, устанавливается командой apt install nginx
· Xray-core с VLESS XHTTP - ядро, которое обрабатывает прокси-трафик, устанавливается скриптом с официального репозитория
· Клиент VLESS (v2rayNG, v2RayTun, Throne) - приложение на телефоне или компьютере для подключения, скачивается из магазина приложений или GitHub

# шагавая инструкция 
Часть 1. Покупка и настройка CDN в Yandex Cloud

-1. Создайте аккаунт и каталог. Зарегистрируйтесь в Yandex Cloud. В консоли создайте каталог (папку), в которой будут жить все ресурсы .
-2. Создайте бакет Object Storage. CDN в Yandex Cloud требует источник (origin). В сервисе Object Storage создайте бакет. Включите публичный доступ на чтение объектов и списка объектов .
-3. Создайте CDN-ресурс. Перейдите в сервис Cloud CDN. Нажмите «Создать ресурс». В настройках укажите:
   · Тип источника: Бакет.
   · Бакет: выберите созданный ранее.
   · Доменное имя: укажите ваш домен, например cdn.вашдомен.ru. Это имя нельзя будет изменить после создания .
   · Заголовок Host: выберите «Свое значение» и укажите <имя_бакета>.storage.yandexcloud.net .
-4. Настройте DNS. После создания ресурса скопируйте сгенерированное доменное имя (вида e1b83ae3********.topology.gslb.yccdn.ru). В панели управления вашим доменом создайте CNAME-запись, указывающую на этот адрес .

# Часть 2. Установка Remnawave

-1. Подготовьте VPS. Вам понадобится сервер на Ubuntu 22.04 или 24.04 с правами root .
-2. Установите Remnawave (All-in-One). Самый быстрый способ — использовать готовый скрипт установщика. Выполните на сервере:
   ```bash
   sudo bash -c "$(curl -sL https://raw.githubusercontent.com/xxphantom/remnawave-installer/main/install.sh)" @ --lang=ru
   ```
   Выберите режим All-in-One (панель и нода на одном сервере) . Альтернативный вариант — следовать официальной инструкции по установке через Docker Compose .
-3. Настройте подключение к CDN. После установки панели вам нужно будет создать в ней inbound (входящее подключение) с типом транспорта XHTTP. В настройках этого inbound укажите домен, который вы настроили в CDN, и порт (обычно 443).
-4. Проверьте работу. В панели Remnawave создайте тестового пользователя, скопируйте ссылку подписки и проверьте подключение через клиент (например, v2rayNG). Трафик должен идти через домен CDN.
